# Exploring Specialized Agents in Microsoft 365 Copilot

A hands-on workshop repository for exploring specialized agents and
agentic experiences across Microsoft 365 Copilot, Microsoft Teams,
SharePoint, and Power Apps.

> **Audience:** Microsoft 365 users, makers, administrators, architects,
> champions, and workshop participants\
> **Format:** Hands-on labs\

## Workshop objectives

By the end of these exercises, you should be able to:

-   Explain when to use a specialized agent instead of standard Copilot
    Chat.
-   Use Analyst to analyze structured data and generate insights.
-   Use Researcher for deep, multi-source research.
-   Use Facilitator to improve Teams meetings.
-   Delegate multi-step work to Copilot Cowork.
-   Create and use scoped SharePoint agents.
-   Explore Copilot in SharePoint, previously referred to as Knowledge
    Agent.
-   Create reusable SharePoint Skills.
-   Turn SharePoint/Microsoft Lists data into an application experience.
-   Recognize where App Builder and Channel Agent fit into the Microsoft
    365 agent landscape.

## Before you begin

Features in Microsoft 365 evolve rapidly. Availability can depend on
your tenant, license, admin configuration, release ring, geography, and
preview/Frontier participation. Use a non-production demo tenant and
non-sensitive sample data for workshop exercises.

For the broadest experience, participants should have:

-   A work or school Microsoft 365 account.
-   A Microsoft Copilot license where required by the exercise.
-   Access to Microsoft Copilot.
-   Access to Microsoft Teams and SharePoint Online.
-   Permission to create/edit content in a workshop SharePoint site.
-   Sample Excel/CSV data for Analyst.
-   Permission to create a scheduled Teams meeting for Facilitator.
-   Cowork enabled and billing/configuration completed if running the
    Cowork lab.
-   Appropriate preview/Frontier access for features marked as preview.

## Suggested workshop flow

Start with **Analyst** and **Researcher** to demonstrate specialized
reasoning. Move to **Facilitator** and **Cowork** to show agents
participating in and acting across work. Finish with the **SharePoint**
labs to demonstrate grounding, solution building, reusable skills, and
app creation.

## Common workshop scenario

To make the labs feel connected, use a fictional organization called
**Contoso Retail**.

Create a SharePoint site called **Contoso Retail Operations** with:

-   A document library containing policies, project plans, product
    briefs, and meeting notes.
-   An `Issues` list.
-   A `Store Launch Tracker` list.
-   An Excel workbook containing monthly sales data.

You can reuse these assets across several exercises.

## Responsible use

Always review AI-generated analysis, citations, actions, documents,
apps, formulas, and meeting notes. Microsoft 365 agents respect the
permissions of the signed-in user, but participants should still avoid
using sensitive production information in a workshop tenant.
